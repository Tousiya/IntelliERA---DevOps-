# IntelliERA DevOps Project

End-to-end DevOps project developed for IntelliERA training.

## Technologies

- Git & GitHub
- Jenkins
- Maven
- Docker
- Ansible
- Terraform
- Kubernetes
- Helm
- AWS
- SonarQube
- JFrog Artifactory
- Prometheus
- Grafana

## Project Objective

To demonstrate an end-to-end DevOps workflow including source code management, continuous integration, containerization, infrastructure provisioning, Kubernetes deployment, and monitoring.

## DevOps Workflow

Developer → GitHub → Jenkins → Maven → SonarQube → Docker → AWS → Kubernetes → Helm → Prometheus → Grafana

## Project Structure

The repository will contain application source code, CI/CD configuration, infrastructure-as-code, Kubernetes manifests, Helm charts, automation scripts, and monitoring configuration.
